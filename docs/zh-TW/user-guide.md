# 玩家指南

這份指南帶你快速掌握 ChunkLand 的日常操作：如何順利圈下第一塊地、調整權限、邀請好友共同建築，以及如何妥善防範熊孩子與闖入者。想查詳細語法可看[指令參考](reference/commands.md)，想了解邊界細節請看[已知限制](limitations.md)。

## 先確認你有權限

剛進伺服器輸入 `/land` 如果看到「你沒有使用這個指令的權限」，別慌張！這是因為外掛預設將所有指令權限保留給管理員（OP）以確保伺服器安全。

請先向服主確認是否已透過權限外掛（例如 LuckPerms）開放圈地權限（清單見[權限參考](reference/permissions.md)），授權後即可順暢使用所有玩家功能。

## 第一次圈地

![圈地三步驟：拿魔杖點兩個角落、選取範圍自動對齊整個區塊、輸入領地名稱並在聊天欄確認](../assets/claiming.png)

圈地流程非常直覺，只要四個步驟：

1. `/land wand` 領取選區魔杖（外觀是一支帶有標記的木棍；每位玩家同時只會持有一支，重複執行會提醒你背包已有魔杖）。
2. 手持魔杖對著欲保護的第一個角落點擊方塊，定下第一角。
3. 走到對角點擊另一個方塊定下對角。畫面上會立即顯示選取範圍是幾乘幾個區塊。
4. 輸入 `/land claim <領地名稱>`（例如 `/land claim Home`）。聊天欄會跳出圈地明細（包含區塊數量、扣款金額（伺服器未開啟購買時為 0）、是否與既有領地重疊，以及最低保護高度），末端附有綠色的 `[確認]` 按鈕，直接點擊聊天欄中的按鈕就能完成圈地！

送出確認後領地即刻建立。

![ChunkLand 邊界示意圖：兩個相鄰區塊之間的領地邊界，兩側分屬不同領地](../assets/land-boundaries.png)

*注：示意圖展示了相鄰區塊間的領地劃分，方便理解區塊邊界概念。*

## 選取範圍怎麼畫

| 你的動作 | 發生什麼事 |
| --- | --- |
| 拿魔杖點擊方塊 | 設定第一角 |
| 再點擊另一個方塊 | 設定對角，形成矩形選取區域 |
| 選區已建立時再次點擊 | 固定第一角，將新點擊處設為第二角，動態縮放範圍 |
| 長時間未操作 | 選取階段逾時重置（預設 600 秒），需重新點選第一角 |

選取範圍一律是以區塊（Chunk）為單位的矩形。目前版本尚未支援逐塊微調，左右鍵效果相同；想修改範圍時，只要再次點擊第二角即可調整。

若選取失敗，常見原因如下：

- **選區踩到別人的地盤**：系統會提示該區域已被佔用，請退回無主之地重新選取。
- **選取的區塊不連續**：領地必須相連，不能跳躍分散。
- **選取逾時（預設 600 秒無操作）**：選取階段過期，請重新設定第一角。
- **領地資料仍在載入中**：請稍候幾秒再試。

單一維度上限為 32 個區塊、單次選取總上限為 1024 個區塊；每位玩家的總領地數、總區塊數與子領地配額由服主設定決定（內建預設為每人 5 塊領地、合計 10 個區塊、單塊領地 10 個區塊）。

## 擴張與縮減

![領地不必是矩形：先圈一塊矩形，再選取更多區塊並擴張，領地就能變成任何相連的形狀；區塊必須以邊相連，領地中間不能有洞](../assets/land-shapes.png)

想擴大或縮小現有領地？流程與圈地相同：先用魔杖劃出要增減的範圍，然後**親自站在自己的領地內**輸入指令：

| 指令 | 效果 | 注意事項 |
| --- | --- | --- |
| `/land expand` | 將選區併入腳下的領地 | 選區必須與現有領地緊密相連，不得留下空洞或與他人重疊 |
| `/land shrink` | 從現有領地中割除選區並退款 | 選區必須全數屬於該領地，縮減後剩餘區域不能被切成多個孤島 |
| `/land unclaim` | 與 `shrink` 相同 | 兩者共用同一套處理流程與權限節點 |

若縮減範圍內含有子領地，指令會提醒你先調整或移除子領地。若縮減後整塊領地不剩任何區塊，系統會提示改用 `/land delete`。

## 子領地劃分

![一塊領地裡有商店與農場兩個子領地，各自有獨立的權限與進出提示](../assets/sublands.png)

子領地讓你在母領地內部劃出獨立的小區域（例如隊友的專屬房間、公共倉庫），並配置專屬權限。流程採「開啟階段 → 畫出選區 → 確認建立」：

1. 站在母領地內輸入 `/land subland select`，聊天欄會顯示這次操作的階段編號。
2. 用魔杖點擊兩角劃定子領地範圍。
3. 依需求輸入 `/land subland create [名稱]`、`update`、`delete` 或 `extend`（若有要求請帶上階段編號）。

兩個容易遇到的小細節：

- **延伸深度後請再次確認**：若執行 `extend` 延伸了保護深度，系統會請你重新執行一次建立或更新確認，直接照提示點擊即可，不必重新劃定選區。
- **保護下限提醒**：若子領地深度超出母領地範圍，指令會提供一組專用指令碼，貼上執行即可繼續。

## 成員管理與訪客封鎖

![誰能做什麼：陌生玩家只能進入，受信任的玩家可以進入、使用與建造，地主另外可以管理，被封鎖的玩家什麼都不能做](../assets/permissions.png)

| 指令 | 效果 |
| --- | --- |
| `/land trust <玩家>` | 授予該玩家領地成員權限（可建築、開箱） |
| `/land untrust <玩家>` | 收回該玩家的成員權限 |
| `/land ban <玩家>` | 封鎖該玩家，禁止進入與使用此領地 |
| `/land unban <玩家>` | 解除封鎖 |

指定玩家時可輸入遊戲 ID 或 UUID。輸入 ID 時，對方**必須曾經登入過伺服器**，系統才能正確解析身分；從未登入過的新名字是查不到的，這是為了防止錯發權限給幽靈帳號的保護機制。

注意：無法對領地主人或伺服器領地執行封鎖。

另外，`/land ban` 是透過邊界推回生效，**並非瞬間傳送離場**：若被封鎖者當下正好站在領地內，會在下一次移動時被推回邊界外約 3 格。連續嘗試闖入時，推回機制有短暫冷卻時間（預設 500 毫秒）。

## 調整這塊領地的權限

ChunkLand 將權限明確分為兩類：

- **玩家權限**：規範「某人能不能做某事」，涵蓋方塊破壞、開容器、工作台操作、開門按鈕、水桶使用、生物互動與進入領地等。地主可以自由逐項調整。
- **領地規則**：規範「伺服器環境機制能不能在此發生」，涵蓋 PVP、爆炸、火焰蔓延、生物破壞、水流、活塞、漏斗跨界與生物生成等。目前由系統預設託管，尚未開放玩家自訂。

調整玩家權限有三種方式：

| 方式 | 適合什麼情況 |
| --- | --- |
| `/land default <動作> <ALLOW\|DENY\|INHERIT>` | 直接修改整塊領地對特定動作的預設值 |
| `/land manage` | 開啟圖形化介面（GUI / 表單）點選切換 |
| `/land binding bind player <玩家> <權限組合>` | 為特定玩家或群組套用一套自訂權限組合 |

`INHERIT` 代表「沿用上一層設定」，等同於不覆寫。

權限組合可透過 `/land profile create` 建立，再以 `/land profile set <組合名> <動作> <狀態>` 填入規則，最後用 `/land binding` 綁定給目標。群組則使用 `/land group` 管理。

### 權限判定順序（為什麼被允許或被拒絕）

判定會由上而下層層比對，一旦在某一層找到明確的允許或拒絕，立即定案。管理員豁免權優先於所有判定。

**玩家權限鏈**

1. 領地主人特權 — 若操作者是地主，直接允許
2. 子領地授權彙總
3. 子領地預設
4. 領地授權彙總
5. 領地預設（`/land default` 修改的即是此處）
6. 世界預設
7. 全域預設（服主於 `config.yml` 配置）
8. 預設阻擋 — 若所有層級皆未定義，一律拒絕

**領地規則鏈**

1. 子領地規則
2. 領地規則
3. 世界預設
4. 全域預設
5. 預設阻擋

注意：領地規則鏈不套用主人特權，環境機制（如防爆）對地主同樣有效。

想快速知道當下的判定結果，站在領地內輸入 `/land explain <動作>` 即可。它會完整列出判定結果、生效層級、地主身分判定與子領地狀態。名稱採用 `ProtectionActionType` 列舉（不區分大小寫），例如 `/land explain BLOCK_BREAK` 或 `block_break`。

## 改名與刪除

改名相當簡單：站在領地內輸入 `/land rename <新名稱>` 即可。若與你擁有的其他領地同名會被拒絕。

刪除領地無法復原，但會全額退款給地主：

1. 站在欲刪除的領地內輸入 `/land delete`。指令會回傳帶有安全版本碼的確認指令。
2. 輸入 `/land delete confirm <版本碼>` 進行最終確認。

版本碼機制能確保你在確認期間，領地若被他人修改過不會被意外誤刪。

## 進入別人的領地時會發生什麼

| 情況 | 你會看到什麼 |
| --- | --- |
| 順利進入 | 動作欄顯示 `已進入 <領地名稱>` |
| 正常離開 | 動作欄顯示 `已離開 <領地名稱>` |
| 進出子領地 | 動作欄顯示 `已進入 <領地> › <子領地>` |
| 被拒絕進入 | 周圍出現紅色邊界粒子，並將你平順退回邊界外約 3 格 |

退回時只會選取已經載入且安全的位置，ChunkLand 絕不會為了尋找落點而額外載入新區塊。若空間不足會自動縮短推回距離；若完全無安全落點，則退回原位或取消該次移動。

領地預設的進入判定目前是**放行**，未被封鎖的訪客可自由參觀。服主可依需求將預設改為拒絕，詳情請見[伺服器管理指南](server-guide.md#陌生人進入預設放行還是關閉)。

## 常用查詢指令

| 指令 | 功用 |
| --- | --- |
| `/land inspect` | 查看腳下領地的名稱、主人、區塊數、子領地數與上限 |
| `/land inspect <玩家>` | 查詢指定玩家的領地配額與狀態 |
| `/land explain <動作>` | 排查特定動作在此處的判定結果與原因 |
| `/land log [篩選條件]` | 查詢領地審計紀錄（支援依玩家、時間、動作篩選分頁） |
| `/land history` | 查詢周圍方塊變更歷史（需伺服器安裝 CoreProtect） |
| `/land manage` | 開啟管理介面（權限清單、成員名單、黑名單管理） |

`/land inspect` 的輸出結果包含便捷點擊按鈕，點擊即可自動填入對應指令。

## 目前版本暫未支援的操作

![領地內的機制：水與岩漿、活塞、漏斗、生物生成照原版運作；PVP、爆炸、火焰蔓延、生物破壞被擋下](../assets/land-rules.png)

為了避免反覆摸索，以下是目前版本的已知限制：

- **十一項環境規則暫無法調整**：包含自訂 PVP、水流與活塞放行等，目前一律遵循伺服器安全預設。
- **點火行為未單獨保護**：火焰蔓延與燒毀方塊會被攔阻，但「拿打火石點火」的瞬間動作尚未納入單獨判斷。
- **管理介面僅列出線上玩家**：若要將離線好友加入信任，請直接使用指令 `/land trust <ID>`。
- **極薄的子領地可能被高速穿過**：進入判定採起終點檢測；若以鞘翅或三叉戟高速穿越單薄邊界，中間過程可能不被捕捉。

更詳盡的行為分析與應對方案請參考[已知限制](limitations.md)。
